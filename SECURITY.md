# Security Policy

## Supported Versions

We provide security updates and fixes for the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

We take the security and integrity of Measured Humanizer seriously. Because this tool inspects and parses markdown and text documents, potential vulnerabilities may include unexpected parser denial-of-service, path traversal, or command injection when integrated into automated workflows or agent environments.

If you discover a security vulnerability:

1. **Do not create a public issue.**
2. Send an email to the project maintainer at `sadhu1998@gmail.com` with the subject line `[SECURITY] Measured Humanizer Vulnerability Report`.
3. Include detailed information to assist us in understanding and reproducing the issue:
   - A description of the vulnerability and its potential impact.
   - Minimal steps or document fixtures to reproduce the behavior.
   - Any proposed fixes or remediations, if available.

### Response Timeline
- **Initial acknowledgment:** within 48 to 72 hours.
- **Assessment and validation:** we will work to evaluate the severity and develop a patch.
- **Public release:** once a patch is tested and merged, a security advisory will be published acknowledging responsible disclosures.
