Why Banned Word Lists Fail

Standard humanizers ban words like "delve" or "seamless". We calibrated a corpus of 10,000+ sentences across human and AI technical writing using Area Under the ROC Curve (AUC, where 0.5 is random chance):

Signal AUC Separation Finding
Paragraph length variance 0.897 AI paragraphs are uniform (stdev 12.8). Human paragraphs vary widely (stdev 28.6).
First-person rate (/1k words) 0.889 Humans averaged 8.18 / 1k words. AI averaged 0.00 (models avoid "we").
Sentence length variance 0.720 Humans swing naturally between 4-word punches and 35-word explanations.
Contraction rate 0.663 Humans write "don't" and "it's"; AI defaults to formal unabbreviated forms.
Promotional words (robust, seamless) 0.535 Near random chance — no consistent directional separation.
Hedging words (may, might, typically) 0.516 Useless heuristic — humans actually hedged more than AI.

Key Capabilities

⚡ Deterministic & Dependency-Free

Runs purely in Node.js standard library with zero runtime npm dependencies. No API keys, no network calls, no black-box classifier latency.

🎯 Prioritized Fix Loop

Reports only the single worst failing dimension per pass. Fixing one dimension at a time prevents agents from trading one flaw for another.

🛡️ Code & URL Integrity Guard

Pass --before orig.md to verify that style improvements never secretly rewrite fenced code snippets or drop source citations.

📦 NPX & Global CLI

Run instantly with npx measured-humanizer or install the standalone CLI script via curl.

🤖 GitHub Action for CI

Drop SadhvikChirunomula/measured-humanizer@v1.0.0 directly into your PR workflows to gate docs automatically.

🔌 Model Context Protocol (MCP)

Includes a stdio MCP server ready to plug into Claude Desktop, Cursor, or autonomous agent loops.
